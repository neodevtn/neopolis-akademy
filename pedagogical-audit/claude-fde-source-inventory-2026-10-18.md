# Inventaire source — Claude Forward Deployed Engineer

- Source authentifiée : parcours Skilljar `https://anthropic-partners.skilljar.com/path/claude-fde`
- Consulté le 18 octobre 2026 dans une session Skilljar autorisée de l’utilisateur.
- Format source : autoformation, durée affichée d’environ 9 h 30.
- Objectif source : accompagner un client depuis un premier cas d’usage vers un pilote opérationnel sur site.
- Prérequis source : expérience de développement et travail direct avec des équipes clientes ; le parcours partage neuf cours avec le parcours Claude Developer ; deux cours supplémentaires restent à réaliser, environ 100 minutes.

## Cours affichés dans l’ordre

1. AI Capabilities and Limitations — 14 leçons affichées dans la fiche du cours.
2. AI Fluency for Builders — environ 45 min ; cadre 4D (delegation, description, discernment, diligence) appliqué au développement.
3. Claude Platform and Model Foundations — environ 60 min ; quatre décisions avant l’écriture d’un prompt : point d’entrée, fonctionnalités, modèle et contexte.
4. Choosing the right Claude model — environ 10 min ; choix du modèle Claude selon la tâche et incidence sur la limite de débit.
5. Claude Platform 101 — environ 90 min ; premier appel API, boucle agentique, outils, extended thinking, skills, MCP, gestion du contexte et agents gérés.
6. Claude Code 101 — environ 60 min ; prototypage dans le dépôt du client.
7. Claude Code in action — environ 60 min ; sessions longues, modes de permission, hooks et vérification dans le dépôt du client.
8. Introduction to Model Context Protocol — environ 60 min ; connexion de Claude aux systèmes du client.
9. Introduction to agent skills — intitulé visible, détails à compléter avec la fiche officielle avant publication.
10. Delivery Methodology — environ 40 min ; qualification du cas d’usage, conception du pilote, capture de la baseline, adoption et risques.
11. Driving enterprise adoption of Claude — environ 60 min ; passage de l’activation à l’échelle, équipe succès, enablement, lancement et identification de la charge de travail suivante.
