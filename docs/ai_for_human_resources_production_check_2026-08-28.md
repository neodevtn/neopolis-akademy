# Contrôle de production — AI for Human Resources

Le checkpoint `93bd3461` a été diffusé sur `https://akademy.neodev.click`. Après propagation, la sonde indépendante de métriques a confirmé sur la carte du catalogue et la fiche de la certification les valeurs dérivées du JSON : **25 activités**, **14 exercices interactifs**, **11 vidéos** et **3 téléchargements**.

Les contrôles locaux pré-publication associés sont archivés dans l’audit d’alignement, la sonde du TP rubricé, la sonde mobile du tri 1.3 et la sonde Projector 1.1. Ils confirment le verrouillage séquentiel, le feedback post-tentative, la contribution de compétence, l’audio/slide Projector, ainsi que l’absence de référence fournisseur dans le contenu pédagogique testé.

Les contrôles apprenant ont ensuite été rejoués sur le domaine publié : le Projector 1.1 rend l’audio et les slides sans référence DataCamp/Copilot visible ; le tri 1.3 conserve le verrou, le feedback et le déverrouillage après réponse correcte ; l’évaluation des 9 TP rubricés rend le feedback Markdown complet et la contribution de compétence, sans commande d’administration affichée.
