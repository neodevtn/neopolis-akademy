# Validation — recommandations et exercices dans l’éditeur

## Recommandations vidéo

Les recommandations vidéo ne sont plus injectées dans chaque vue de chapitre. Elles disposent d’une destination unique, **Fin de module · recommandations**, au sein de la leçon. Le panneau rappelle explicitement que la sélection s’affiche à l’apprenant après la dernière étape du module.

## Exercices

Les exercices sont désormais filtrés par leçon **et** par chapitre. Une vue de chapitre n’affiche donc plus les exercices des autres chapitres. Chaque carte sépare le type d’interaction, le titre, le contexte pédagogique et la consigne destinée à l’apprenant, avec un bouton **Modifier** visible.

## Contrôles réalisés

Le chapitre *Couche des capacités* a été vérifié : aucun panneau de recommandations répété n’est présent dans son édition, et l’accès de fin de module est visible dans la navigation de leçon. Le panneau de recommandations unique a été contrôlé par son URL directe, avec le bon état actif dans la navigation.

La validation complète confirme la compilation TypeScript et **101 tests** locaux réussis, hors test Resend qui dépend du réseau externe. Le validateur de cours renvoie **0 erreur** ; les avertissements restants concernent des options de QCM quasi similaires et sont antérieurs, sans lien avec la présente modification.
