## Périmètre canonique

Le manifeste décrit le cours **L’IA pour les data analysts**, constitué de **4 chapitres**, **39 activités** et **11 leçons Projector**. Les activités répartissent 11 vidéos, 21 expériences visuelles, 4 tris et 3 QCM. Les objectifs couvrent le cadre GCSE, l’audit de qualité des données, l’enrichissement, l’identification et la vérification d’insights, le prototypage de tableaux de bord et le cadre S.P.O.T.

Les ressources nécessaires sont locales dans le paquet et doivent être exposées par la bibliothèque média Neopolis ; aucune URL DataCamp source ne doit être servie dans le cours publié.
