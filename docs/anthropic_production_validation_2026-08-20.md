# Contrôle de production — audit Anthropic

Le 20 août 2026, le parcours **Claude Certified Architect – Foundations** a été vérifié en production sur l’écran « Exercice : Introduction à l’AI Fluency ». L’écran affiche le libellé de contenu officiel Anthropic, l’objectif de réflexion, les trois questions attendues, la ressource téléchargeable et la navigation verrouillée avant l’activité requise. Le chargement initial a été observé puis le contenu réel a été rendu correctement dans la session apprenant.

Le contrôle final en production confirme également la zone de réponse libre standard, le minimum de 50 mots, l’action de soumission, les tags AI Fluency / Responsible AI et l’explication visible du verrou : « Pour continuer : Soumettez l’activité de validation requise. » Le bouton suivant est donc bloqué pour une raison pédagogique explicite, et non par une règle invisible ou une donnée manquante.
