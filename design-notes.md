# Design Notes - Refonte Neopolis Akademy

## Logo Neopolis Development (original)
- Texte "Neopolis" en bleu navy avec un globe terrestre stylisé intégré dans le "o"
- "Development" en gris/rouge en dessous
- Style corporate classique

## Design System choisi : Hybride Linear + Cursor
- **Fond** : Near-black (#050507) avec une teinte bleutée subtile
- **Accent principal** : Gradient vibrant bleu-violet → corail (#6366f1 → #f97316) — symbolise la transformation IA
- **Accent secondaire** : Cyan électrique (#06b6d4) pour les éléments interactifs
- **Texte** : Blanc pur (#fafafa) pour les titres, gris clair (#a1a1aa) pour le body
- **Surfaces** : Charcoal (#0f0f12) pour les cartes, hairline borders (#1f1f28)
- **Typographie** : Inter (display 600, body 400) avec tracking négatif agressif
- **Animations** : Framer Motion pour les entrées, gradient mesh animé sur le hero
- **Style** : "Dark luxury AI" — minimaliste, dense, techniquement sophistiqué
